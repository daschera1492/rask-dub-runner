# rask-dub-runner

دوبلهٔ ویدیو با **Rask.ai** — بدون آپلود خودِ ویدیو.

## چطور کار می‌کند

1. ویدیوی مبدأ روی ماشین خودمان می‌ماند؛ فقط **صدا** بریده و آپلود می‌شود
   (`ffmpeg -vn` → mp3).
2. هر تکه (حداکثر ۱ دقیقه) در یک **اکانت موقت** Rask دوبله می‌شود:
   آدرس Gmail موقت از emailnator + ثبت‌نام/تأیید Cognito + دو مرحلهٔ bootstrap
   (`rst.rask.ai/api/accounts/v1/users` و `POST /api/user`).
3. فایل برگشتی Rask فقط برای **صدا** استفاده می‌شود؛ تصویرِ جایگزین (placeholder)
   دور ریخته می‌شود.
4. هر تکهٔ دوبله‌شده با `fitChunkAudio` دقیقاً هم‌طول همان بازهٔ اصلی می‌شود،
   تکه‌ها به ترتیب الحاق می‌شوند و صدا با `-c:v copy` روی **ویدیوی اصلی خودمان**
   مux می‌شود → نه واترمارک، نه افت کیفیت، نه آپلود تصویر.

## محدودیت‌ها (تست‌شده)

- هر اکانت تازه: **۳ دقیقه** دوبله و **۵ پروژه**.
- هر پروژه حداکثر **۱ دقیقه** → هر تکه یک دقیقه از اعتبار را مصرف می‌کند
  (حتی اگر ۵۰ ثانیه باشد). پس تکه‌ها ~۵۵ ثانیه‌ای انتخاب می‌شوند.
- هر ۳ تکه = یک اکانت تازه. ویدیوی بلندتر = اکانت‌های بیشتر (خودکار).

## اجرا

```bash
# نصب ffmpeg لازم است (ffmpeg و ffprobe در PATH)
INPUT_URL="C:\path\video.mp4" TARGET_LANG=Persian node scripts/run.mjs
```

یا لینک مستقیم:

```bash
INPUT_URL="https://example.com/video.mp4" TARGET_LANG=Persian PARALLEL_CHUNKS=3 node scripts/run.mjs
```

خروجی: `work/out/<name>-fa-ir.mp4`

## متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `INPUT_URL` | — | مسیر فایل یا لینک مستقیم (اجباری) |
| `TARGET_LANG` | `Persian` | نام یا کد زبان Rask (`fa-ir`) |
| `CHUNK_SECONDS` | `55` | طول هر تکه (۲۰ تا ۵۹) |
| `PARALLEL_CHUNKS` | `3` | تعداد پروژهٔ هم‌زمان روی یک اکانت |
| `MAX_CHUNKS` | `0` | تست سریع: فقط N تکهٔ اول |
| `MAX_ACCOUNTS` | `20` | سقف اکانت‌های موقت |
| `OTP_WAIT_SECONDS` | `180` | انتظار برای کد ایمیل |
| `ALLOW_PARTIAL` | `false` | تکهٔ ناموفق را با سکوت پر کن |
| `OUTPUT_NAME` | خالی | نام فایل خروجی |
| `WORK_DIR` | `work` | پوشهٔ کار و کش تکه‌ها |
| `PROXY_OXYLABS` | خالی | پروکسی Oxylabs: `pr.oxylabs.io:7777:customer-resi_<ID>:<PASSWORD>` |
| `PROXY_ENABLED` | خودکار | `false`/`0` = خاموش؛ خالی = اگر `PROXY_OXYLABS` ست شده باشد روشن |
| `PROXY_COUNTRIES` | `us` | کشورهای خروجی، با کاما (`us,de,nl,gb`) |
| `PROXY_SESSION_MINUTES` | `30` | مدت چسبیدن هر اکانت به همان IP |

## پروکسی (اختیاری ولی توصیه‌شده)

هر اکانت یک **IP residential چسبندهٔ جدا** می‌گیرد و از لحظهٔ ثبت‌نام تا آخرین
پروژه‌اش با همان IP بیرون می‌رود:

- ثبت‌نام/تأیید Cognito، همهٔ فراخوانی‌های `rst.rask.ai` و `app.rask.ai`،
  و آپلود تکهٔ صدا → از پروکسی.
- دانلود ویدیوی مبدأ و دانلود فایل دوبله‌شده (لینک امضاشدهٔ S3) → مستقیم،
  تا پهنای باند residential صرف ویدیو نشود.

اگر `PROXY_OXYLABS` ست نشده باشد، رانر با IP خودش کار می‌کند و در لاگ
`[proxy] off — PROXY_OXYLABS is not set` چاپ می‌شود. اگر `PROXY_ENABLED=true`
صریح داده شود ولی سکرت خالی باشد، اجرا همان اول با پیام واضح متوقف می‌شود.

## نکات

- ورک‌فلو: `.github/workflows/dub.yml` (Actions → Rask dub).
- کش تکه‌ها در `work/state.json` است؛ اجرای دوباره فقط تکه‌های ناقص را می‌فرستد.
- اینباکس emailnator عمومی است: فقط برای کد ورود یک‌بارمصرف.
